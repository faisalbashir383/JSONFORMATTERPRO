What is JSON Schema?

JSON Schema is a vocabulary that allows you to annotate and validate JSON documents. It defines the structure, data types, and constraints that your JSON data must follow. This is essential for API validation, configuration file validation, and data quality assurance.

Common schema keywords: type, properties, required, minimum, maximum, pattern, enum, items, minLength, maxLength, format.

JSON Schema Validator FAQ

What JSON Schema drafts are supported?

This validator supports JSON Schema Draft 4, Draft 6, Draft 7, and Draft 2020-12. It automatically detects the draft version from your schema's $schema keyword.

What is the difference between Draft 7 and Draft 2020-12?

Draft 2020-12 introduces prefixItems for tuple validation, $dynamicRef for dynamic references, replaces definitions with $defs, and has improved vocabularies for conditional validation.

How do I use required fields in JSON Schema?

Add a "required" array at the object level with property names that must be present: { "required": ["name", "email"] }

Can I validate nested JSON objects?

Yes! Define nested schemas within "properties" of parent objects, or use "$ref" to reference reusable schema definitions in "$defs".

How do I validate array items?

Use "items" to define the schema for array elements. Add "minItems", "maxItems", and "uniqueItems" for additional constraints.

What is the $ref keyword?

$ref references other schemas using JSON Pointer (e.g., "#/$defs/address") or external URIs. It enables schema reuse and modular design.
