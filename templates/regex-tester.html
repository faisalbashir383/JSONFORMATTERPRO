🎯 Regex Flags

  • g - Global: find all matches
  • i - Case insensitive matching

📝 Character Classes

  • \d - Any digit (0-9)
  • \w - Word character (a-z, A-Z, 0-9, _)
  • \s - Whitespace
  • . - Any character except newline
  • [abc] - Character set

🔢 Quantifiers

  • * - Zero or more
  • + - One or more
  • ? - Zero or one
  • {n} - Exactly n times
  • {n,m} - Between n and m times
