Frequently Asked Questions

What is JSON?

JSON (JavaScript Object Notation) is a lightweight data interchange format that's easy for humans to read and write, and easy for machines to parse and generate. It's widely used for APIs, configuration files, and data storage.

How does auto-format on paste work?

Simply paste your JSON into the editor and it automatically detects and formats it with proper indentation. No clicking required - our smart paste detection beautifies your JSON instantly and shows a "Formatted" status.

What is the Monaco Editor?

Monaco Editor is the same powerful code editor that powers VS Code. It provides IntelliSense, syntax highlighting, bracket matching, code folding, find & replace, multi-cursor support, and many other professional-grade features.

How do I switch between dark and light themes?

Click the theme toggle button (moon/sun icon) in the navigation bar or preview modal. The editor theme changes instantly to match. Your preference works across both the main editor and fullscreen preview.

What keyboard shortcuts are available?

Ctrl+F for Find, Ctrl+H for Replace, Ctrl+G for Go to Line, F1 for Command Palette, Alt+Click for multi-cursor, Ctrl+Mouse Wheel for zoom, Ctrl+/ for toggle comment, and Escape to close modals. All VS Code shortcuts work!

How do I zoom in/out of the editor?

Hold Ctrl (Cmd on Mac) and scroll with your mouse wheel to zoom in or out. This is perfect for presentations or when working with dense JSON data that's hard to read at normal size.

Can I search and replace in my JSON?

Yes! Press Ctrl+F to open the Find dialog, Ctrl+H for Find and Replace. You can search with regular expressions, match case, match whole word, and replace single occurrences or all at once throughout your JSON.

Is my data secure when using this tool?

Absolutely. All JSON processing happens entirely in your browser using JavaScript. Your data is never sent to any server, ensuring complete privacy and security.

Can I convert JSON to other formats?

Yes! JSON Formatter Pro supports conversion to XML, CSV, and YAML formats. Use the Actions dropdown to select your desired output format. Note: After conversion, use Clear to reset before pasting new JSON.

What features does the fullscreen preview have?

The fullscreen preview includes all Monaco Editor features plus theme toggle, format, minify, copy, and download buttons. You can edit, search, zoom, and use all keyboard shortcuts right in the preview modal.

How is JSON Formatter Pro different from JSONLint?

JSON Formatter Pro uses the Monaco Editor (VS Code's engine) offering IntelliSense, find & replace, theme toggle, auto-format on paste, zoom, multi-cursor, code folding, and command palette. Plus JSON to XML/CSV/YAML conversion, all client-side with no signup required.
