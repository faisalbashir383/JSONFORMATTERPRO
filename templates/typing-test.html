❓ Frequently Asked Questions

What is a good typing speed? ▼
An average typing speed is around 40 WPM. Professional typists typically achieve 65-75 WPM. Expert typists can reach 80-100+ WPM.
How is WPM calculated? ▼
WPM = (Characters Typed / 5) / Minutes. We divide by 5 because the average word length in English is 5 characters.
What is a code typing test? ▼
A code typing test measures how fast you can type programming code including brackets, semicolons, and operators. Select Python, JavaScript, HTML, or SQL mode to practice!
How does the leaderboard work? ▼
After completing a test, enter your name to save your score to the global leaderboard. Your rank is calculated based on WPM and accuracy. Filter by mode to see rankings for specific difficulty levels.
Why use typewriter sounds? ▼
Typewriter sounds provide satisfying audio feedback that can help maintain rhythm and make typing practice more enjoyable. Toggle sounds on/off as you prefer.
